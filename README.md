# 🎬 Movie Ticket Booking System

A full-stack **Movie Ticket Booking System** built using **Java, Spring Boot, React.js, MySQL, and Microservices**. The application allows users to browse movies, view show schedules, select seats, and book tickets through a responsive and user-friendly interface.

---

## 🚀 Features

### 👤 User Features
- User Registration & Login
- Secure Authentication
- Browse Movies
- View Movie Details
- View Show Timings
- Seat Selection
- Book Movie Tickets
- Booking History
- Responsive UI

### 👨‍💼 Admin Features
- Admin Login
- Add, Update & Delete Movies
- Manage Shows
- Manage Theaters
- View Bookings
- Dashboard for Movie & Booking Management

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/riya45610/movie-ticket-booking-system.git
```

---

### Backend Setup

```bash
cd backend
```

Configure your MySQL database in:

```
application.properties
```

Run the application

```bash
mvn spring-boot:run
```

---

### Frontend Setup

```bash
cd frontend
```

Install dependencies

```bash
npm install
```

Run

```bash
npm start
```

---

## 🗄 Database

Create a MySQL database

```sql
CREATE DATABASE movie_booking;
```

Update your database credentials inside

```
application.properties
```
